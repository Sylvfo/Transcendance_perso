DATABASE SCHEMA (OVERVIEW)
===========================

Users:
  - id (PK, UUID)
  - email (unique, string)
  - password_hash (string)
  - username (unique, string)
  - avatar_url (string, nullable)
  - online_status (boolean, default: false)
  - created_at (timestamp)
  - updated_at (timestamp)

Friends:
  - id (PK)
  - user_id (FK → Users)
  - friend_id (FK → Users)
  - created_at (timestamp)
  - Constraint: user_id ≠ friend_id

Games:
  - id (PK, UUID)
  - white_player_id (FK → Users)
  - black_player_id (FK → Users)
  - status (enum: pending, ongoing, completed)
  - winner_id (FK → Users, nullable)
  - result (enum: white_win, black_win, draw, null)
  - moves (JSON array or separate table)
  - pgn (string, nullable) - for chess notation
  - created_at (timestamp)
  - updated_at (timestamp)

GameStatistics:
  - id (PK)
  - user_id (FK → Users, unique)
  - total_games (int, default: 0)
  - wins (int, default: 0)
  - losses (int, default: 0)
  - draws (int, default: 0)
  - rating (float, default: 1200)
  - updated_at (timestamp)

Messages:
  - id (PK)
  - sender_id (FK → Users)
  - receiver_id (FK → Users)
  - content (text)
  - read (boolean, default: false)
  - created_at (timestamp)

(More details to be added as project progresses)


KEY TECHNICAL CHALLENGES
========================

1. Real-time Move Synchronization
   - Ensure both players see moves instantly
   - Handle network latency & packet loss
   - Prevent race conditions

2. Chess Logic Complexity
   - Implement all chess rules correctly
   - Legal move generation & validation
   - Check/checkmate detection
   - Castling, en passant, promotion

3. AI Implementation
   - Balance difficulty vs performance
   - Implement efficient evaluation function
   - Use minimax with alpha-beta pruning
   - Avoid blocking the UI during AI thinking

4. Concurrent Users
   - Multiple simultaneous games
   - WebSocket connection management
   - Database transaction handling
   - Reconnection to ongoing games

5. Authentication & Security
   - Secure password storage (bcrypt + salt)
   - JWT token expiration & refresh
   - Input validation & sanitization
   - HTTPS for all connections
