ft_transcendence - CHESS GAME WITH TOURNAMENTS
================================================

TECH STACK (FINAL)
==================

DEPLOYMENT SETUP
================

Docker Compose structure:
  - Frontend service (React, port 3000)
  - Backend service (Express, port 5000)
  - PostgreSQL service (port 5432)

Single command to run:
  docker-compose up

Environment variables:
  - DATABASE_URL
  - JWT_SECRET
  - NODE_ENV
  - REACT_APP_API_URL

DATABASE SCHEMA (OVERVIEW)
===========================

Users:
  - id (PK)
  - email (unique)
  - password_hash
  - username
  - avatar_url
  - online_status
  - created_at

Friends:
  - id
  - user_id
  - friend_id (user_id)
  - created_at

Games:
  - id
  - white_player_id (FK)
  - black_player_id (FK)
  - status (ongoing, completed)
  - winner_id (FK, nullable)
  - moves (JSON array or separate table)
  - created_at
  - updated_at

Tournaments:
  - id
  - name
  - status (registration, ongoing, completed)
  - bracket (JSON structure)
  - created_at

Messages:
  - id
  - sender_id (FK)
  - receiver_id (FK)
  - content
  - created_at

(More details to be added as project progresses)
